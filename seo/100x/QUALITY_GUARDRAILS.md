# Vivit Group — Content Quality Guardrails

## Every publishable page must
1. Target one primary search intent.
2. Have a unique title, H1, and answer angle.
3. Provide an immediate direct answer near the top.
4. Include substantial original explanation.
5. Include useful subtopics, examples, checklists, or frameworks.
6. Link to the relevant commercial service page.
7. Link to 2–5 related authority pages.
8. Avoid unsupported claims, fabricated case studies, fake awards, and invented performance metrics.
9. Use real Vivit examples only when evidence is available.
10. Include Arabic and English versions only when each version is written naturally for that language.
11. Avoid keyword stuffing.
12. Avoid doorway city pages.
13. Consolidate overlapping queries instead of creating duplicate pages.
14. Add structured data only when it matches visible content.
15. Update high-value pages when the underlying service or search intent changes.

## Cannibalization rule
If two target queries would produce substantially the same answer, they belong on one page rather than separate pages.

## AEO rule
Important questions should have concise, self-contained answers before deeper explanation.

## GEO rule
Entity facts must be consistent across Vivit Group, Vivit Marketing, Vivit Tech, website, LinkedIn, Facebook, Instagram, Google Business Profile, and public references.

## Review rule
Only authentic customer reviews and testimonials may be published or requested.
