# Vivit Group — Editorial Priority Model

## Score each content idea from 0–3 on
- Commercial intent
- Service relevance
- Buyer urgency
- Distinctness from existing content
- Ability to demonstrate expertise
- Internal-link value
- AEO answerability
- GEO/entity reinforcement

Maximum score: 24.

## Priority
- 20–24: publish first
- 16–19: high priority
- 12–15: authority support
- Below 12: merge, defer, or discard
