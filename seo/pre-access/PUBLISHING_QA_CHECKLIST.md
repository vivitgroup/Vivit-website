# Publish-Ready SEO / GEO / AEO QA Checklist

Before any page is published:

## Search intent
- One clear primary intent
- No duplicate intent with another page
- Primary query mapped
- Supporting queries mapped

## Content
- Direct answer near top
- Original useful explanation
- No unsupported superlatives
- No invented metrics
- No fake testimonials
- Real examples where available
- Clear CTA

## On-page
- Unique title
- Unique meta description
- One H1
- Logical H2/H3
- Descriptive URL
- Internal links
- Breadcrumb
- Image alt
- Canonical
- hreflang if paired

## Technical
- 200 status
- indexable
- mobile usable
- fast enough
- no JS-only critical text
- structured data valid and visible-content aligned

## Entity
- Vivit Group naming consistent
- Egypt / 6 October context accurate
- Relevant Vivit Marketing / Vivit Tech relationship clear
- Official social references consistent

## AEO/GEO
- Key questions answered directly
- Important facts are self-contained
- Citations/evidence available where needed
- Definitions are concise and extractable
