# Proof Intake Matrix

This is the final evidence layer required before publishing strong case studies.

## For each project collect
Client name (publishable? yes/no)
Industry
Service(s)
Project date
Challenge
Scope
Deliverables
Public URL
Approved screenshots/assets
Performance metrics with source
Client quote with approval
Team involved
Technology/platforms used
Before/after evidence
Permission to name client
Permission to publish logo
Permission to publish results

## Case study status
Draft
Evidence collected
Client approval pending
Approved
Published

## Rule
No metric, testimonial, client logo or named case study is published without evidence and permission where required.
