# Vivit Group Sitemap Plan

## sitemap.xml index
- sitemap-core.xml
- sitemap-services-en.xml
- sitemap-services-ar.xml
- sitemap-articles-en.xml
- sitemap-articles-ar.xml
- sitemap-case-studies.xml
- sitemap-images.xml if image volume and ownership justify it
- sitemap-videos.xml if production/video pages are indexable and hosted with stable metadata

## Include only
- 200-status canonical URLs
- indexable pages
- preferred language URLs
- final service/article URLs

## Exclude
- redirects
- 404/410
- admin
- internal search
- filtered duplicates
- tracking parameters
- preview pages
- duplicate language states on the same URL

## Update rule
lastmod should reflect meaningful content updates, not every deploy.
