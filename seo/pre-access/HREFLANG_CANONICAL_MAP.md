# Hreflang + Canonical Rules

## Pattern
English canonical:
https://www.vivit-group.com/en/{path}/

Arabic canonical:
https://www.vivit-group.com/ar/{path}/

## hreflang example
<link rel="alternate" hreflang="en" href="https://www.vivit-group.com/en/marketing/atl/" />
<link rel="alternate" hreflang="ar" href="https://www.vivit-group.com/ar/marketing/atl/" />
<link rel="alternate" hreflang="x-default" href="https://www.vivit-group.com/en/marketing/atl/" />

## Rules
- Each page self-canonicals.
- Arabic and English pages reference each other.
- Never canonical Arabic to English or English to Arabic.
- Do not use hreflang between unrelated content.
- Keep language URL pairs content-equivalent in purpose, not literal translations.
