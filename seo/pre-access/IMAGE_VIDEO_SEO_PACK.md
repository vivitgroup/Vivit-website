# Image & Video SEO Pack

## Images
Use descriptive filenames:
vivit-trade-marketing-retail-activation-egypt.jpg
vivit-btl-brand-activation-egypt.jpg
vivit-crm-dashboard-egypt.jpg

Alt text should describe the visible image naturally. Do not stuff keywords.

## Video
For every important video:
- Unique title
- Description
- Thumbnail
- Upload date
- Duration
- Transcript or useful text summary
- VideoObject schema when eligible
- Stable embed/content URL
- Relevant service-page link

## Media production portfolio
Each project should include:
Client/industry
Service delivered
Creative objective
Format
Production scope
Public evidence
Related service links

## Social-to-site reuse
Important social media campaigns should have a permanent owned-page reference when rights and client approval allow.
