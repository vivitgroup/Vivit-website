# Google Search Console Setup Checklist

## Property
Prefer Domain property for vivit-group.com if DNS verification is available.

## After verification
- Submit sitemap
- Inspect homepage
- Inspect service hubs
- Inspect priority service pages
- Review Page Indexing
- Review robots/canonical
- Track Core Web Vitals
- Track top queries and pages
- Segment brand vs non-brand
- Segment Arabic vs English
- Create service clusters: Marketing, ATL, BTL, Trade, Digital, Production, Web, Apps, CRM, ERP, AI
