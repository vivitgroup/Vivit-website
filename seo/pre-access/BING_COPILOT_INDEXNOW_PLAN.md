# Bing / Copilot / IndexNow Plan

## When website access is available
1. Verify vivit-group.com in Bing Webmaster Tools.
2. Submit sitemap.xml.
3. Enable IndexNow if the stack supports it.
4. Submit new and materially updated URLs.
5. Monitor crawl errors and indexed pages.
6. Keep canonical, hreflang and structured data aligned with Google implementation.

## Why this matters
Bing search visibility contributes to Microsoft search surfaces and can improve discoverability in the broader Microsoft ecosystem.

## IndexNow rules
Submit only canonical public URLs.
Do not submit tracking URLs, redirects, private pages, previews, or duplicates.
