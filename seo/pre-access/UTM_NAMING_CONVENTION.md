# UTM Naming Convention

utm_source = platform or referrer
utm_medium = paid-social / organic-social / email / referral / cpc
utm_campaign = campaign-name
utm_content = creative-or-placement
utm_term = keyword where applicable

## Example
?utm_source=linkedin&utm_medium=organic-social&utm_campaign=vivit-ai-solutions&utm_content=ai-agents-post

Use lowercase, hyphens, stable names, and no personal data.
